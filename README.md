# AI Game Arena 

An AI-powered mini game platform where users can play games like Maze Solver, Tic Tac Toe, AI Quiz, and other logic-based challenges while exploring Artificial Intelligence algorithms and gameplay performance analysis.

## Features

- Interactive "GUI built with Tkinter"
- Multiple "AI-powered games"
- AI Auto-Solve functionality
- Intelligent **hint system**
- Move tracking and score management
- Performance "Analyzer" dashboard
- Game data logging using "CSV files"
- Visual performance analysis with "charts and metrics"

## Technologies Used

- Python
- Tkinter
- CSV for data logging
- Matplotlib for performance charts
- Artificial Intelligence algorithms

## Games Included

### - Maze Solver
### - Tic Tac Toe
### - Memory Pattern Game
### - Logic Mini Games
### - AI Quiz
### - Performance Analyzer

## Algorithms Used

- Breadth First Search (BFS)
- Depth First Search (DFS)
- Minimax Algorithm

## Setup Instructions to Run the Program

1. **Clone this repo** to your PC:

   ```bash
   git clone https://github.com/minahiltahir-ai/AI-Game-Arena.git
   ```

2. Go to the **Project Folder**:

   ```bash
   cd AI-Game-Arena
   ```

3. Install required **Python libraries** (if needed).

4. Run the **Main Program**:

   ```bash
   python AI_GameArena.py
   ```
